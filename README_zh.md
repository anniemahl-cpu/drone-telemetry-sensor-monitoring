# DroneGuard 无人机遥测数字孪生与异常检测平台

DroneGuard 是原 ESP32 无人机遥测项目的软件延伸。它不需要新的电子元件或嵌入式操作，使用原有 CSV 作为真实台架基线，并通过可复现的软件仿真研究采样率、传感器噪声和异常检测。

## 数据真实性

- `REAL BENCH DATA`：原有 ESP32 台架实验，不称为真实飞行数据。
- `SIMULATED FLIGHT DATA`：软件数字孪生产生的数据。
- `MODEL INFERENCE`：实验性模型推断，不是经过认证的安全诊断。
- 原 INA240 数值是未经校准的模拟输出，不能直接称为安培数。

## 主要功能

- 自动检查 CSV 格式、时间戳、缺失值和采样率
- 验证加速度模长与 ADC 电压换算的一致性
- 计算角速度模长、动态加速度、jerk 和运动状态
- 生成九种正常或异常仿真场景
- 模拟电池荷电状态、电压下垂、噪声、漂移、冻结与丢包
- 比较工程规则、Isolation Forest 和 Random Forest
- 输出混合风险分数、风险时间线和可下载报告
- 研究从 100 Hz 降到 2 Hz 时模型性能的变化
- 自动化测试与 GitHub Actions

## 本地运行

```bash
pip install -e .[dev]
pytest -q
streamlit run app.py
```

## 必须保留的限制说明

现有真实数据约为 2 Hz、持续约一分钟，能够支持宽泛的静止/运动分析，但不能验证电机高频振动、真实飞控或多类真实无人机故障。仿真数据用于控制变量和测试算法，不能冒充真实飞行证据。
