# Data Files

This folder contains the project data used for analysis.

- `integrated_telemetry_60s.csv`: raw integrated telemetry dataset
- `integrated_telemetry_60s_with_time_s.csv`: same data with relative time added
- `integrated_telemetry_60s_analysis.xlsx`: Excel analysis workbook
- `ina240_all_test_data_0611.xlsx`: INA240 test data
- `mpu6050_stationary_baseline_0603.xlsx`: initial MPU6050 baseline data
